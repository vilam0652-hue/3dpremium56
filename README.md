# Капля

Игры и учебные приложения для 4 класса. Каждое приложение — отдельный APK для Android, который собирается автоматически. Главный сайт (`index.html`) — витрина, откуда приложения скачиваются.

**Сайт:** https://vilam0652-hue.github.io/kaplya/ (после включения GitHub Pages)
**Скачать APK:** раздел [Releases → apk](../../releases/tag/apk)

## Как устроено

- `apps/<id>/` — приложение (HTML/JS). `shared/` — общая дизайн-система (`k.css`, `k.js`), шрифты, three.js и свечение.
- `apps.json` — список приложений: название, пакет Android, описание.
- `android/` — одна Android-обёртка (WebView) на все приложения. `android/build-all.sh` собирает APK для каждого.
- `.github/workflows/apk.yml` — при каждом пуше в `main` GitHub собирает все APK и выкладывает их в релиз `apk`.
- `tools/inline-apps.py` — обновляет список приложений на главном сайте после правки `apps.json`.

## Подпись APK

Без настроек APK подписываются общим ключом сборки из кэша Actions. Чтобы обновления всегда ставились поверх, добавь в **Settings → Secrets and variables → Actions** свой ключ: `KAPLYA_KEYSTORE_BASE64`, `KAPLYA_KEYSTORE_PASSWORD`, `KAPLYA_KEY_ALIAS`, `KAPLYA_KEY_PASSWORD`.

## ИИ в «Бадди»

Чат работает через OpenRouter на бесплатных моделях. Ключ вводит взрослый в приложении: вкладка «Я» → «ИИ-собеседник». Ключ не хранится в коде. Для класса лучше указать свой сервер (поле «Свой сервер»), который держит ключ у себя: он получает `{ messages }` и возвращает `{ reply }`.
